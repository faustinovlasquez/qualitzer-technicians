# Permisos al iniciar sesión: APK 1.0.108

Mantiene todo lo de la [actualizacion 1.0.107](ACTUALIZACION-1.0.107.md) y agrega:

- **Al iniciar sesión la app pide, una tras otra, las ventanas del teléfono** para permitir notificaciones, cámara y ubicación. Se repite en cada sesión nueva.
- **"Recibir avisos" queda activado** al aceptar las notificaciones, aunque antes estuviera desactivado.
- Si las notificaciones están bloqueadas en el teléfono, se ofrece abrir Ajustes. Los permisos ya concedidos o bloqueados no se vuelven a pedir.
